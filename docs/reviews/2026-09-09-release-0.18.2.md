# 0.18.2 Windows 릴리즈 검증

0.18.1 이후 확인한 주요 결함 네 가지를 수정한 패치 릴리즈입니다. [수정 검증 보고서](2026-09-09-fix-verification.md)에 동작 변경, 회귀 테스트 및 독립 Red Team 결과를 기록했습니다. 해당 보고서의 0.18.1은 버전 변경 전 검증 시점을 가리킵니다.

## 새 버전 검증

- `package.json`, `package-lock.json`: 0.18.2. 플러그인 매니페스트: 0.18.2.0.
- `npm run release:windows`: 성공. 전체 테스트 53개 파일 / 474개, Companion 테스트 34개 파일 / 309개 통과.
- 버전 일치, 타입 검사, 플러그인 빌드, 브리지 검증, 매니페스트 검증, Companion 빌드, NSIS 설치 파일 생성 완료.
- ZIP 내부 네 가지 배포 파일의 SHA-256을 `SHA256SUMS.txt`와 대조하여 모두 일치함을 확인했습니다.
- 압축된 플러그인의 매니페스트 버전 0.18.2.0을 확인했습니다.
- 패키지 `app.asar`의 버전 0.18.2, main·preload·renderer 진입 파일 다섯 개와 현재 빌드 파일의 바이트 일치를 확인했습니다. Companion에 동봉된 플러그인도 배포 플러그인과 일치합니다.
- 패키지의 Electron 43.1.1 / Node 24.18.0 환경에서 패키지에 포함된 node-pty로 PowerShell을 실행하여 출력 표식과 종료 코드 0을 확인했습니다. GUI와 Claude는 실행하지 않았습니다.

검증 도구의 첫 실행은 Windows ASAR 경로 구분자 처리 문제로 실패했고, 이를 보정했습니다. PTY 검증 도구는 종료 확인 후 자체 프로세스를 명시적으로 끝내도록 보정한 뒤 통과했습니다. 이 과정에서 제품 코드는 변경하지 않았습니다.

## 배포 파일

- 파일: `Claude-StreamDeck-0.18.2-Windows.zip`
- SHA-256: `D31891701624A53D576B259286EE0C414A6956D258410A24FE574723976E7203`
- 내용: Companion 설치 파일, Stream Deck 플러그인, 한국어 설치 안내서, `Install.cmd`, `SHA256SUMS.txt`.

설치 프로그램 실행, 설치된 앱 업데이트, 실제 Claude 호출과 GUI 수동 검증은 수행하지 않았습니다. 최초 검토의 LOW/WATCH 및 개발 의존성 항목은 이번 패치 범위 밖입니다.
