# 0.18.3 Windows release verification

This release includes the previously local Companion shutdown fix and automatic
explorer refresh. Filesystem changes refresh loaded folders while preserving
expanded state, surviving selection, and scroll position. Automatic refresh
defers during filename editing, context menus, drag targets, and hidden windows.

## Fresh verification

- `npm run release:windows`: passed on Windows.
- Version consistency: package and lockfile 0.18.3, plugin manifest 0.18.3.0.
- Full test suite: 57 files / 502 tests passed.
- Companion test suite: 38 files / 337 tests passed.
- Typecheck, plugin build, bridge verification, manifest validation, Companion
  build, plugin packaging, and NSIS installer packaging passed.
- `git diff --check`: passed.
- ZIP contains the five expected distribution files; all four internal SHA-256
  checksums match. The embedded plugin manifest reports 0.18.3.0.
- Packaged `app.asar` reports 0.18.3. Its five main/preload/renderer entry files
  match the fresh build byte-for-byte. Its bundled plugin matches the release
  plugin byte-for-byte.
- Packaged Electron 43.1.1 / Node 24.18.0 loaded the packaged node-pty module,
  observed the expected PowerShell output, and received exit code 0.
- Freshly bundled IPC code in an isolated hidden Electron window handled actual
  window destruction, delayed output, and actual PTY exit with zero uncaught
  exceptions.
- The packaged preload and renderer passed an isolated hidden Electron smoke:
  nested create/rename/delete, stable DOM on content saves, selection cleanup,
  inline editing deferral, and a burst of 20 files.
- Companion build label: `ver. 2026.09.11.14.47`.
- Independent release-blocker review: approved with no concrete blocker. The
  reviewer also passed all 28 tests across the four new regression test files.

The GUI smoke uses the development Electron executable to load the packaged

manual acceptance with the user's Stream Deck and Claude projects were not run.
